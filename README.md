# Aprendendo arrays em Java

Este repositório reúne uma lista de 50 exercícios de arrays da disciplina Programação em Java — Banco de Dados. São programas independentes, com atividades de leitura, percursos e manipulação de valores.

Os arquivos estão em [src/ProgramacaoJavaBancoDados/Arrays](src/ProgramacaoJavaBancoDados/Arrays).

## Como executar

1. Abra o repositório no IntelliJ IDEA e marque a pasta `src` como código-fonte, se necessário.
2. Abra uma das classes `Exercicio01` a `Exercicio50`.
3. Execute o método `main` e informe os dados pedidos no console.

Outros exemplos de aula estão em [aprendendo-array](https://github.com/Elton-Silva607/aprendendo-array).
